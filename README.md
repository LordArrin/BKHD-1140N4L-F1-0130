Flashing the BIOS:
1) Unzip the BIOS package, copy the EFI folder in the root folder to the root directory of a USB drive formatted as FAT32.
2) Plug in this USB stick, remove all hard drives from the mini PC.
3) Boot from the USB drive.
4) Type fs0: then press Enter.
5) Next type 1.nsh and press Enter to start the BIOS flash.
